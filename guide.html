Шаг 2
⚔️ Боевая система

!бой — рейтинговая дуэль. !бой @ник — товарищеский бой.

🎲 Как работает бой

⚡ Инициатива
Оба бросают d20 + DEX. Победитель ходит первым ⚡. Равенство — случай.
🎯 Попадание
d20 + ATK ≥ 10 + DEF защитника → попал. Иначе → 🛡️ блок.
💥 Крит / ❌ Провал
d20 = 20 → двойной бросок урона. d20 = 1 → урон 0.
💨 Уклонение
d20 ≤ 2 + DEX защитника → урон 0. Проверяется до расчёта урона.
🛡️ Редукция
Каждое очко DEF снижает урон на 5%. Минимум 1 урон.
⏱ Ход боя
Атакующий ↔ защитник до HP ≤ 0. Лимит 20 раундов. Ничья → победа по HP.

🐲 Бездна Разлома

PvE-режим. !данж — бесконечные волны монстров. Каждая 5-я — босс. 💀 Смерть перманентна для забега.

🚪 Вход
Случайная пассивка + случайный фамильяр.
🌊 Волны
Бесконечные. Каждая 5-я — босс (HP×1.5, ATK+2, DEF+1).
💚 Отхил
14 + волна×2 HP. После босса — полный отхил.
🎲 Артефакты
35% после волны, 70% после босса. +2 к статам.
💰 Награда
+1💎 за 3 волны. Босс: 1–3 трофея фракции.

HP = 0 → конец забега. Рекорд сохраняется.
